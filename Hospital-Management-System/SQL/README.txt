# SQL Yapısı

Bu klasörde, hastane yönetim sistemine ait tüm şema bileşenlerinin SQL tanımları yer almaktadır.

## Dosyalar

- **01_CreateTables.sql** – Projedeki tüm tabloların oluşturulması Foreign Key ilişki yapısının kurulması
- **02_StoredProcedures.sql** – Randevu atama, doktor müsaitlik kontrolü vb. işlemler
- **03_Triggers.sql** – Verilerin kontrolü ve otomatik hareketleri yöneten trigger'lar
- **04_Views.sql** – Power BI raporları için kullanılan özetlenmiş görünümler
